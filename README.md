# «Досье» — цифровой кабинет юридической компании

Веб-сервис для небольшой юридической компании: клиентский кабинет (мобильный интерфейс) и рабочее место юриста (десктопная панель) работают с общими данными.

Подробная инструкция для пользователей и план запуска в работу — в [ИНСТРУКЦИЯ.md](ИНСТРУКЦИЯ.md).

**Адреса:**

| Адрес | Что открывается |
|---|---|
| `#/c/home` | клиентский кабинет |
| `#/l/overview` | панель юриста |
| `#/demo` | оба интерфейса рядом с подсказками по сценарию |
| `#/` | стартовый экран |

## Запуск

Сервис статический, сборка не нужна. Нужен любой веб-сервер (ES-модули не работают при открытии файла напрямую):

```bash
python -m http.server 5173
```

в корне репозитория и открыть `http://localhost:5173/`.

## Публикация

Сайт статический, подходит GitHub Pages: Settings → Pages → Deploy from a branch → `main`, папка `/ (root)`. Файл `.nojekyll` уже добавлен.

## Как устроено

```
index.html              единая страница, маршруты через #hash
css/app.css             дизайн-система: токены, компоненты, адаптивность, микроанимации
js/main.js              маршрутизация, перерисовка, события, push-уведомления из другой вкладки
js/store.js             общее хранилище (localStorage) и синхронизация вкладок
js/seed.js              демо-данные: юристы, клиенты, обращения, дела, документы, переписка
js/actions.js           бизнес-действия: обращение → дело → документы → статусы → чат → счета
js/format.js            справочники статусов и категорий, форматирование дат и сумм, выборки
js/client.js            экраны клиента
js/panel.js             экраны юриста
js/parts.js             общие компоненты: ход дела, лента сообщений, превью документа
js/demo.js              демо-режим «клиент + юрист»
img/                    логотип, иконки
```

Каждое действие одной стороны оставляет следы для другой: системное сообщение в чате, уведомление клиенту, запись в ленте юристов, строку в истории дела. Вкладки синхронизируются через событие `storage`, поэтому клиентский кабинет и панель юриста, открытые в разных вкладках одного браузера, видят изменения друг друга сразу.

## Что сейчас демонстрационное

- **Данные** хранятся в `localStorage` браузера. Для реальной работы `store.js` нужно заменить на API: функции в `actions.js` уже описывают все операции и легко переводятся в запросы к серверу.
- **Файлы** не загружаются на сервер: сохраняются название, тип, размер и превью фотографий.
- **Оплата** имитируется. Для реальных платежей кнопки «Оплатить через СБП» и «Банковской картой» подключаются к платёжному сервису.
- **Вход** не требуется: клиент — Елена Морозова, юрист выбирается в меню профиля в панели.
- Контакты компании и команда задаются в `seed.js` и в разделе «Настройки» панели. «Сбросить демо-данные» возвращает исходный набор.
